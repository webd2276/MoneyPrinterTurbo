# MoneyPrinterTurbo 💸

### All-in-One AI Short Video Generator

## Features 🎯

### Creation Entry Points and Workflow

- [x] Offers four ways to use it: **AI Agent, WebUI, API, and CLI**, so you can get started quickly or plug into automated workflows
- [x] Automatically completes script, voiceover, footage, subtitles, music, and editing from a topic, and also supports custom content at every stage
- [x] Supports **batch generation of multiple videos**, task history, and import, export, and restore of generation settings and API keys

### Scripts and Model Services

- [x] Supports AI-generated or rewritten **multilingual video scripts**, and you can also use your own custom script
- [x] Supports mainstream model services including [Kimi / Moonshot AI](https://platform.kimi.com?track_id=track-6eec1e56a4494e52adcaebbcbbefce59&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://dashscope.console.aliyun.com/apiKey), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [Volcengine Ark](https://www.volcengine.com/activity/ai618?utm_campaign=hw&utm_content=hw&utm_medium=devrel_tool_web&utm_source=OWO&utm_term=MoneyPrinterTurbo), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimaxi.com/), and [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Compatible with unified gateways, aggregation platforms, and local runtimes such as [Shengsuanyun](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [API Route](https://www.api-route.com/), [Fluxion AI](https://fluxionai.space/register?source=github&campaign=moneyprinterturbo&promo=MONEYPRINTERTURBO), [Ollama](https://ollama.com/), [Claude Code subscription](https://code.claude.com/docs), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), and [Pollinations AI](https://enter.pollinations.ai/)

### Video and Image Footage

- [x] Supports uploading your own **local images and videos**, or fetching HD stock footage from [Pexels (free)](https://www.pexels.com/api/), [Pixabay (free)](https://pixabay.com/api/docs/), and [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Supports [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT) text-to-video, generating raw footage at `768P`/`2K` and 4–15 seconds, adapted to three aspect ratios: `9:16`, `16:9`, and `1:1`
- [x] Supports [Shengsuanyun AI video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), generating multiple AI video clips and composing the final video using the project's existing voiceover, subtitle, and editing pipeline
- [x] Natively integrates [Volcengine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey), generating coherent video visuals from script segments
- [x] Supports [WaveSpeed AI](https://wavespeed.ai) text-to-video, quickly generating original footage from script keywords
- [x] Supports [OFox](https://ofox.ai) multi-model text-to-video; one API key can call models such as Seedance and Wan
- [x] Generates 3–12 second AI video footage through the asynchronous [MuAPI](https://muapi.ai) text-to-video interface, with configurable endpoint, aspect ratio, resolution, and polling parameters
- [x] Supports [OpenAI-compatible text-to-image](https://platform.openai.com/docs/guides/image-generation), connecting to cloud services or custom image gateways and converting generated images into animated video clips
- [x] Supports adjusting clip duration, picture fitting mode, and footage matching order to suit different aspect ratios and narrative pacing

### Voiceover, Subtitles, and Music

- [x] Supports three voiceover modes: automatic voiceover, uploaded voiceover, and no voiceover, with voice preview and full voiceover preview
- [x] Integrates voiceover services including **Edge TTS (free, no API key required)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Kokoro, Fish Audio, and ModelBest VoxCPM
- [x] Supports automatic subtitle generation, with adjustable font, position, color, size, outline, and background style
- [x] Supports random, local, and AI-generated background music, with independent volume control

### Final Video and Publishing

- [x] Supports portrait `9:16 (1080×1920)`, landscape `16:9 (1920×1080)`, and square `1:1 (1080×1080)`
- [x] Supports one-click **cross-platform publishing**: after generation, videos can be uploaded automatically to **TikTok, Instagram, and YouTube Shorts**

## Requirements 📦

- Recommended systems: Windows 10, macOS 11.0 or later, and mainstream Linux distributions
- Local deployment requires Python 3.11 or later; Python 3.11 is recommended
- A GPU is not required, but if you want local transcription, faster video processing, or smoother batch generation, a discrete graphics card with dedicated VRAM is recommended

| Item | Minimum  | Recommended        | Ideal              |
| ---- | -------- | ------------------ | ------------------ |
| CPU  | 4 cores  | 6 to 8 cores       | 8 cores or more    |
| RAM  | 4 GB     | 8 GB               | 16 GB or more      |
| GPU  | Optional | 4 GB VRAM or more  | 8 GB VRAM or more  |

- If you mainly rely on cloud LLMs, cloud TTS, and online footage sources, CPU and RAM matter more than the GPU
- If you enable `faster-whisper`, batch generation, or heavier local processing pipelines, a GPU will noticeably improve speed

## Installation and Deployment 📥

### Prerequisites

- Local deployment requires Python 3.11 or later
- Windows users should avoid project paths containing Chinese characters, special characters, or spaces

#### ① Clone the Code

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② First-Time Configuration

On first launch, the project automatically creates `config.toml` from `config.example.toml`; there is no need to create the config file manually. Before using cloud LLMs, online footage, AI video, or similar services, fill in the corresponding API keys under the basic settings in the WebUI.

### Docker Deployment 🐳

#### ① Start Docker

If Docker is not installed yet, please [download and install Docker Desktop](https://www.docker.com/products/docker-desktop/) first.

Windows users can refer to Microsoft's documentation:

1. [Install WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
2. [Work with Docker containers in WSL](https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> `docker-compose.release.yml` is recommended by default; it pulls the prebuilt image directly from GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> If you need to rebuild the image locally, you can keep using `docker compose up`.
> Before the first start, copy `config.example.toml` to `config.toml` so the container can mount it.

#### ② Access the WebUI

Open your browser and visit http://127.0.0.1:8501

#### ③ Access the API Docs

Open your browser and visit http://127.0.0.1:8080/docs or http://127.0.0.1:8080/redoc

> By default, the API only allows same-origin web pages. Only when a standalone web frontend needs to call the API directly from another origin should you configure trusted origins through the `CORS_ALLOWED_ORIGINS` environment variable, for example `http://localhost:3000,https://frontend.example.com`. curl, Postman, n8n, and other server-side calls are not subject to CORS restrictions.

### Manual Deployment 📦

> Video tutorials

- [Complete usage demo](https://v.douyin.com/iFhnwsKY/)
- [How to deploy on Windows](https://v.douyin.com/iFyjoW3M)

#### ① Create a Virtual Environment

[uv](https://docs.astral.sh/uv/) is recommended for managing the Python environment and dependencies. The project supports Python 3.11 or later; the examples below use Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

If you don't want to use `uv` for now, you can also keep using `venv + pip`

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Notes:

- `pyproject.toml` is the main dependency definition file
- `uv.lock` is the lock file; running `uv sync --frozen` by default is recommended
- `requirements.txt` is kept only for compatibility with the legacy `pip` installation method

#### ② Start the WebUI 🌐

Note: run the following commands from the project's `root directory` of MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

You can also run `webui.bat` from CMD.
`webui.bat` prefers the project's `.venv` or the Python bundled with the one-click package; if no project Python is found but `uv` is installed, it automatically switches to `uv run streamlit`.
To allow other devices on the local network to access the WebUI, first run `set MPT_WEBUI_HOST=0.0.0.0`, then run `webui.bat`.

###### macOS or Linux

```shell
sh webui.sh
```

The script automatically uses the project's virtual environment or `uv`, and picks an available local port. To allow other devices on the local network to access it, run:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

After launch, the browser opens automatically (if it opens blank, try **Chrome** or **Edge**)

#### ③ Start the API Service 🚀

```shell
uv run python main.py
```

If you have already activated the virtual environment manually, you can also run directly:

```shell
python main.py
```

#### ④ Pure Command-Line Mode (No Browser) ⌨️

If you can't use a browser or port forwarding, you can generate videos directly from the command line. The simplest full video generation command is:

```shell
uv run python cli.py --video-subject "How AI is changing daily life"
```

Subtitle style and voiceover parameters take values in the following priority: **explicit command-line arguments > WebUI settings saved under `[ui]` in `config.toml` > built-in defaults**. Other generation settings (such as background music, number of videos, number of paragraphs, etc.) do not automatically inherit the values saved in the WebUI. If you chose to upload your own audio in the WebUI, the command line must explicitly pass `--custom-audio-file`, because the audio path is not saved.

To see the full commands, parameter descriptions, and usage, run:

```shell
uv run python cli.py --help
```

To run multiple tasks sequentially, provide a UTF-8 JSON array or JSONL manifest via `--batch-file`. CLI arguments serve as global defaults, and each object can override `VideoParams` fields:

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

A manifest can contain at most 100 tasks and must not exceed 1 MiB. All entries undergo parameter and local file pre-checks before the first task starts; a failure in one task does not stop subsequent entries, and a unified JSON summary is output at the end. Relative custom audio and local footage paths in the manifest are resolved relative to the manifest's directory.

## Voiceover, Subtitles, and Music 🎙️

### Speech Synthesis

**Azure TTS V1** in the WebUI is based on **Edge TTS**, which is free and requires no API key. The project also supports **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **MiniMax TTS**, **ElevenLabs TTS**, self-hosted **Chatterbox TTS**, self-hosted **Kokoro TTS**, **Fish Audio TTS**, [ModelBest VoxCPM TTS](https://platform.modelbest.cn/console/docs/api/audio), as well as a no-voiceover mode.

You can choose the provider and voice directly in the WebUI and fill in the required credentials as prompted by the interface. Edge TTS does not need an API key; [Azure TTS V2](https://portal.azure.com/) and other cloud services require credentials from the corresponding platform. For the list of Edge TTS voices, see: [Voice list](./docs/voice-list.txt).

ModelBest VoxCPM requires an API key and a model ID that supports `speech_synthesis`. The service returns WAV audio via SSE, and the project automatically converts it to the MP3 used by the video pipeline. Besides plain text synthesis, you can also upload reference audio to clone a speaker's voice; when "Preserve the rhythm and emotion of the reference audio" is enabled, this audio is reused by default and its exact verbatim transcript is required, or you can pick a separate clip to demonstrate rhythm and emotion and continue the delivery via `prompt_audio` and `prompt_text`. The WebUI can use local Whisper to automatically generate an editable transcript draft. Uploaded files are limited to 20 MiB, and each converted WAV is limited to 5 MiB. Reference material is used only for the current browser session and task, and is not written to config, presets, task history, or logs.

### Subtitle Generation

Two subtitle generation methods are currently supported:

- **edge**: generates subtitles from TTS timestamps. It is fast, needs no GPU, and is the default mode.
- **whisper**: transcribes audio locally with `faster-whisper`, suitable when more accurate subtitle timing is needed. The model must be downloaded on first use.

Change `subtitle_provider` in `config.toml` to switch modes. Whisper uses the roughly 3 GB `large-v3` by default; for a smaller, faster model, you can use the roughly 1.6 GB `large-v3-turbo`:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> On first use of Whisper, the program automatically downloads the model from Hugging Face. If your network cannot download it automatically, you can manually download `whisper-large-v3` from [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

After downloading and extracting, put the entire directory in `.\MoneyPrinterTurbo\models`; the final path should be `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

### Background Music

Background music for videos is located in the project's `resource/songs` directory.

> The project currently includes some default music taken from YouTube videos. If there is any infringement, please delete it.

### Subtitle Fonts

Fonts used to render video subtitles are located in the project's `resource/fonts` directory; you can also add your own fonts.

## FAQ 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normally, ffmpeg is downloaded automatically and detected automatically.
However, if there is a problem with your environment and it can't be downloaded automatically, you may encounter the following error:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

In this case, you can download FFmpeg from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/). After extracting it, set `ffmpeg_path` to the actual installation path.

```toml
[app]
# Set according to your actual path; note that the Windows path separator is \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

This problem is caused by the system's open file limit, and can be solved by raising that limit.

Check the current limit

```shell
ulimit -n
```

If it is too low, you can raise it, for example

```shell
ulimit -n 10240
```

</details>
